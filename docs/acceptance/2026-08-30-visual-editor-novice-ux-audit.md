# 可视化装修小白操作体验审查

日期：2026-08-30  
范围：管理后台“可视化装修 / 实时预览与编辑”

## 当前已具备的保护

- 左侧内容可直接点击，右侧打开对应的结构化编辑项，常用内容不必先理解后台菜单结构。
- 修改会先在左侧展示草稿效果；离开、切换内容或刷新正式数据时，会提醒未保存修改。
- 图片、跳转、分类、状态等高频字段已使用素材选择器、链接选择器、下拉或分段控件。
- 保存前有必填、价格、库存、重复名称/跳转等校验；正式保存后的最近操作可一键回退。

## 仍会让小白犹豫的地方

### P0：先完成这三项

1. 固定“本次修改”操作条
   - 编辑任意内容后，在页面底部固定展示“已修改 2 项、未保存、放弃、检查并保存”。
   - 点击后先显示本次变更摘要，例如“频道名称：热销爆款 -> 热销推荐”，再确认正式发布。
   - 将“刷新正式数据”改为更直白的“回到已发布版本”，并说明会放弃当前草稿。

2. 保存前做可视化体检
   - 不只提示字段错误，还应按“必须处理 / 建议处理”列出问题，并能点击定位到对应内容。
   - 必须处理：缺图、未选分类、无效价格库存、跳转目标不存在或已下架。
   - 建议处理：图片比例不合适、标题过长、商品售价高于市场价、跳转内容无库存等。
   - 体检通过后再显示“确认发布”，避免小白因为一次保存失败而不知从哪里改起。

3. 补齐可编辑地图与完整内容入口
   - 给可点击区域增加持续可见的细边框或“可编辑”标记；不可编辑区域说明“此处暂不支持装修”。
   - 预览中仅展示前几条内容时，增加“查看全部 12 个 Banner / 商品 / 频道”，避免用户误以为其余数据消失或无法编辑。
   - 选中某个内容后，自动滚动到预览内对应位置，并在右侧显示“正在编辑：首页 Banner 2”。

### P1：显著降低误操作与猜测成本

4. 在预览中测试跳转
   - 链接选择完成后，在右侧显示人话名称，例如“跳到：商品『东阿阿胶糕』”，而不是只显示路径。
   - 增加“在预览中试打开”按钮，在模拟小程序内打开目标；无效目标直接指出原因并提供重新选择。

5. 图片按实际展示比例检查
   - 上传或选择图片后，显示其在手机内的裁切效果和推荐比例。
   - 对过小、比例明显不合适、主体可能被裁掉的图片给出警告；提供裁切或更换图片入口。

6. 新手模式与更多设置分层
   - 默认只显示名称、图片、跳转、售价、状态等日常字段。
   - 排序权重、市场价、库存调整原因等放到“更多设置”，并保留明确说明和推荐默认值。
   - 这样客户不会在每次改名称时面对大量与当前操作无关的输入项。

7. 把回退做得更可见、更具体
   - 保存成功后立即显示“已发布，30 秒内可撤销”的操作提示。
   - 右侧保留最近操作列表，直接写出修改内容、时间和操作者，而不是让用户猜“一键回退”会恢复什么。

### P2：交付后可逐步增强

8. 增加更多真实页面状态的预览：分类、搜索、购物车、个人中心和结算页，并提供手机尺寸切换。

9. 提供“发送到微信预览”或预览二维码。后台模拟器用于编辑，真机预览用于确认文字、图片和安全区效果。

10. 加入只提供建议、不自动发布的 AI 助手：根据图片建议标题、卖点和标签；检查夸大功效词、图片不清晰、文案过长和内容缺失。食品类文案必须由人工确认后才能保存。

11. 草稿由浏览器本地保存不适合多人协作。后续可升级为服务端草稿、编辑占用提示和版本冲突提醒，避免两个人相互覆盖。

## 建议实施顺序

先做 P0 三项。它们不需要改动商品、内容、权限或回退的既有业务接口，只是在现有可视化装修外补一层“修改摘要、发布体检、完整内容导航”。完成后，小白能明确知道：我改了什么、还缺什么、保存后会影响哪里、出错如何回到原状。
