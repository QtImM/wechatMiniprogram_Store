## 4. 首页模块

**MP-01 首页正常加载**

```text
1. 启动小程序后等待首页数据加载完成
2. 确认顶部显示"药食同源" Logo 和标语"安心选购，便捷到家"
3. 确认搜索栏显示"搜索商品、品牌"占位文字
4. 确认 Banner 轮播图正常显示（至少 1 张）
5. 确认金刚区频道图标正常显示（新品推荐、热销商品等）
6. 确认双栏区：左侧"热销推荐"有商品图和价格，右侧"新品尝鲜"和"品牌精选"卡片正常
7. 确认下方商品双列瀑布流正常展示（商品图、名称、价格、绿色"选"按钮）
```

> [[MP-01-首页加载]](screenshots/MP-01-首页加载.png)

**MP-02 Banner 轮播** h

```text
1. 观察首页顶部 Banner 区域
2. 等待 4 秒确认轮播图自动切换
3. 确认底部指示点跟随当前图片移动（绿色活跃点）
4. 手动左右滑动 Banner，确认切换流畅
5. 点击某张 Banner 图，确认跳转到对应页面（如有链接）
```

**MP-03 金刚区频道入口**

```text
1. 在首页金刚区逐一点击各频道图标
2. 点击"新品推荐"，确认跳转到新品推荐页
3. 返回首页，点击"热销商品"，确认跳转到热销商品页
4. 返回首页，点击"分类"相关入口，确认跳转到分类 Tab

```

> [[MP-03-金刚区频道]](screenshots/MP-03-金刚区频道.png)

**MP-04 分类 Tab 切换**

```text
1. 在首页顶部找到分类横滑 Tab（精选、滋补养生、茶饮花茶等）
2. 当前"精选"Tab 处于选中状态，下方有绿色短横线
3. 点击"滋补养生"Tab
4. 确认绿色下划线移动到"滋补养生"
5. 确认 Banner、金刚区、双栏区隐藏（非精选 Tab 不显示这些区域）
6. 确认显示分类专区 Banner 和该分类下的商品列表
7. 点击"精选"Tab 切回，确认恢复 Banner 等首页元素
```

> [[MP-04-分类Tab切换]](screenshots/MP-04-分类Tab切换.png)

**MP-05 活动 Tab 切换**

```text
1. 确保当前在"精选"分类下
2. 找到"今日主推"、"热销爆款"、"新品上架"三个 Tab
3. 当前"今日主推"高亮，底部有绿色指示条
4. 点击"热销爆款"Tab
5. 确认商品列表切换为热销商品，Tab 高亮跟随
6. 点击"新品上架"Tab
7. 确认商品列表切换为新品
```

```text
2. 确认标题显示"FEATURED"和"精选专题"
3. 确认右侧有"查看全部"入口
4. 确认专题卡片横向排列，每张含图片、标题、副标题和起步价
5. 左右滑动确认滚动流畅
```

## 5. 搜索模块

**SR-01 搜索页加载**

```text
1. 点击首页搜索栏"搜索商品、品牌"进入搜索页
2. 确认搜索输入框自动聚焦，显示键盘
3. 确认下方显示"热门搜索"关键词列表
4. 如已登录且之前搜索过，确认显示"搜索历史"区域和"清空"按钮
```

> [[SR-01-搜索页]](screenshots/SR-01-搜索页.png)

**SR-02 关键词搜索**

```text
1. 在搜索框输入"枸杞"
2. 点击键盘上的"搜索"按钮
3. 确认展示搜索结果列表
4. 确认每个结果包含商品图片、名称和价格
5. 确认结果与关键词相关
```

> [[SR-02-搜索结果]](screenshots/SR-02-搜索结果.png)

**SR-03 搜索建议/联想词**

```text
1. 清空搜索框，输入"阿"（一个字即可）
2. 等待 300ms 左右
3. 确认下方出现搜索建议列表（如"阿胶糕"等）
4. 点击某个建议词
5. 确认使用该建议词执行搜索，显示搜索结果
```

> [[SR-03-搜索建议]](screenshots/SR-03-搜索建议.png)

**SR-04 搜索结果排序**

```text
1. 在搜索结果页，确认顶部有"综合"和"价格"排序选项
2. 当前"综合"高亮
3. 点击"价格"，确认商品按价格排序，"价格"高亮，旁边显示↑
4. 再次点击"价格"，确认切换为降序，箭头变为↓
5. 点击"综合"切回默认排序
```

> [[SR-04-搜索排序]](screenshots/SR-04-搜索排序.png)

**SR-05 搜索分类筛选**

```text
1. 在搜索结果页，点击顶部"分类"选项
2. 确认展开分类标签面板
3. 点击某个分类标签
4. 确认搜索结果按该分类过滤，标签高亮
5. 点击另一个分类切换
```

> [[SR-05-搜索分类筛选]](screenshots/SR-05-搜索分类筛选.png)

**SR-06 搜索无结果**

```text
1. 清空搜索框，输入"xyzabc99999"
2. 执行搜索
3. 确认显示空状态提示，如"没有找到相关商品"
4. 确认不展示任何商品卡片
```

> [[SR-06-搜索无结果]](screenshots/SR-06-搜索无结果.png)

**SR-07 搜索历史管理**

```text
1. 先执行 2-3 次不同的搜索（如"枸杞"、"阿胶"）
2. 清空搜索框，返回搜索初始状态
3. 确认"搜索历史"区域显示刚才搜索过的关键词
4. 点击某个历史词，确认执行该搜索
5. 点击"清空"按钮
6. 确认搜索历史列表消失
```

> [[SR-07-搜索历史]](screenshots/SR-07-搜索历史.png)

## 8. 购物车模块

**CA-01 购物车加载**

```text
1. 确保已登录且之前添加过商品到购物车
2. 点击底部 Tab 栏"购物车"
3. 确认顶部显示服务保障：正品保障、售后服务、满XX包邮
4. 确认购物车列表显示：商品图片、名称、规格、价格、数量步进器
5. 确认底部结算栏显示：全选按钮、合计金额、编辑/结算按钮
```

> [[E-01-购物车列表]](screenshots/E-01-购物车列表.png)

**CA-02 空购物车**

```text
1. 清空购物车（删除所有商品）或以未购物账号登录
2. 进入购物车页面
3. 确认显示购物车图标/插画
4. 确认显示"购物车是空的"文字
5. 确认显示"去逛逛"按钮
6. 点击"去逛逛"，确认跳转到首页
```

> [[E-02-空购物车]](screenshots/E-02-空购物车.png)

**CA-03 勾选/全选**

```text
1. 在购物车列表中，取消勾选某个商品前的圆形勾选框
2. 确认底部合计金额减少（减去该商品金额）
3. 重新勾选该商品
4. 点击底部"全选"按钮
5. 确认所有商品被勾选，合计金额为全部商品总价
6. 再次点击"全选"，确认全部取消勾选
```

> [[E-03-勾选全选]](screenshots/E-03-勾选全选.png)

**CA-04 数量加减**

```text
1. 找到购物车中某个数量为 1 的商品
2. 确认"−"按钮置灰不可点击
3. 点击"+"按钮，确认数量变为 2，合计金额增加
4. 点击"−"按钮，确认数量回到 1
5. 确认合计金额实时更新
```

> [[E-04-数量加减]](screenshots/E-04-数量加减.png)

**CA-05 左滑删除**

```text
1. 在购物车列表中，对某个商品条目向左滑动
2. 确认右侧露出红色"删除"按钮
```
