## 6. 前端 UI 复现步骤

### 6.1 前置准备

```text
1. 启动后端：cd shop-backend && mvn spring-boot:run -pl shop-server -Dspring-boot.run.profiles=dev,local
2. 启动前端：cd shop-admin && pnpm dev
3. 浏览器打开 http://localhost:8848
4. 使用 admin / admin123 登录
5. 打开浏览器 DevTools (F12) → Network 面板，筛选 XHR/Fetch
```

## 7. 发现的已知问题

| 编号 | 问题 | 严重度 | 说明 |
|------|------|--------|------|
| K-01 | 内容管理状态切换 Bug | 中 | Banner/频道/品牌/专题的启用/禁用开关，前端 `handleStatusChange` 调用全量更新接口，后端执行全量字段校验导致"名称长度不正确"错误。需增加独立的 status-only 更新端点或前端传递完整字段 |
| K-02 | ~~早期演示数据编码问题~~ | ~~低~~ | **已修复** — 通过 `V20260823_01` 迁移脚本修复 ID 240001-240006 及关联表的 UTF-8 双重编码问题，中文名称现已正确显示 |
| K-03 | 分类 update-status 端点为 PUT 方法 | 低 | `POST /admin-api/product/category/update-status` 返回 405，实际应使用 PUT 方法，前端已适配 |
| K-04 | 交易模块分页参数差异 | 低 | 订单/售后使用 `page/size` 参数而非 `pageNo/pageSize`，与其他模块不一致，建议统一 |
