# 前后端功能检查执行计划

1. 固定分支和最新CI，建立模块及用例证据矩阵。
2. 用实际JS/Vue源码行为测试复现支付异常、支付结果页导出及评价并发问题，修复后回归。
3. 检查所有注册页面、请求/会话/上传工具、购物车地址结算、后台API契约和权限，发现实际问题同样添加针对性测试并修复。
4. 执行后端完整测试、后台类型构建、工具测试、静态门禁、隔离交易及数据库一致性、恢复容器验收；补足现有可重复的接口场景。
5. 审核测试失败，更新验收报告、状态及教程差异；只推送用户分支。真实微信及客户环境保持待验证，列出精确缺项，不伪造资金、真机或客户签字。
6. 关闭地址演示数据阻断：固定地区数据来源和完整性，生成后端离线资源、替换地区查询、保存时校验真实层级，测试陕西/广东/直辖市和非法组合；不批量修改旧地址。
