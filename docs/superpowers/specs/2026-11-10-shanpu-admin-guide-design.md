# 陕铺名称与后台图文教程规格

## 目标

将小程序的应用名称、默认页面标题和分享品牌统一为用户指定的“陕铺”，交付可编辑、可直接阅读的后台图文教程，说明商品维护与首页内容编辑的操作步骤。

## 范围

- 基于 GitHub `origin/main` 的 `92d83bd`；已获用户授权完整应用远端增删。
- 复用现有商品管理、库存工作台、素材库、可视化装修与权限管理能力。
- 教程区分微信公众平台的官方小程序名称、应用内品牌文案和商品名称。后台品牌管理维护的是推荐品牌内容，不能替代微信官方改名。
- 用当前管理后台源码配合隔离的演示接口截图；截图注明演示数据，不连接真实数据库或提交真实业务修改。
- Markdown 为可编辑正文，HTML 为离线阅读版，共用本地截图；提供登录、查找商品、改名称与简介、改价格、改图片与详情、调库存、上下架、新增商品、可视化装修、保存与回退、常见问题和交付权限说明。

## 验收

- 小程序名称配置及默认导航标题精确为“陕铺”，保留现有 AppID。
- 教程中的菜单、按钮、字段和保存行为与源码和截图一致。
- 示例价以元填写；明确 SKU 逐项设置、库存调整的增量语义、草稿和正式保存的区别。
- 图片与 HTML 相对链接在离线目录中有效，截图可放大阅读。
- 不写入实际账号密码；正式后台网址与账号由交付负责人单独提供。
- 静态配置解析、截图操作检查、文档链接检查与 `git diff --check` 通过后更新项目状态。
