# 管理后台列表横向查看规格

## 目标

后台所有数据列表在列数较多或屏幕宽度不足时，必须允许用户通过底部横向滚动条查看完整列内容，避免列被挤压、文字错位或操作按钮难以点击。

## 规则

- 所有 `el-table`，包括页面主列表、抽屉/弹窗内明细表和工作台记录表，统一启用常显横向滚动条。
- 滚动条使用清晰、可拖拽的样式；不覆盖表格内容。
- 现有固定操作列继续固定，权限和数据逻辑不改变。
- 不为短表格制造额外空白，只有内容宽度超过容器时才产生实际横向滚动距离。

## 验收标准

- 商品、订单、库存、素材、售后、支付、退款、内容、系统等列表页面均具备可见的横向滚动条。
- 缩窄浏览器窗口后，可向右拖动查看完整列与操作项。
- 表头和表体横向滚动保持同步，固定列仍可正常使用。
