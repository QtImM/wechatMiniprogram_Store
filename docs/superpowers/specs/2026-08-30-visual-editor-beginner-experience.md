# 可视化装修台小白操作体验规格

## 目标

让没有后台使用经验的客户运营人员，能够在不理解商品、内容位或 URL 等技术概念的前提下，完成首页内容和常用商品展示信息的查看、修改、预览、保存与回退。

## 使用原则

- 可视化装修必须是后台一级菜单，名称使用业务语言，不要求用户先理解“内容管理”。
- 首次进入必须能看懂三步操作：选择页面内容、在右侧修改、确认保存。
- 所有需要用户填写的数据均在控件旁说明用途、是否必填、合法格式和前端展示位置。
- 图片从素材库选择，跳转从链接选择器选择，分类/状态/商品类型通过下拉或分段控件选择；不让用户手填技术路径。
- 价格统一使用人民币元，库存只允许非负整数，排序只允许范围内的非负整数。
- 保存前必须阻止不完整或不规范数据；保存后必须明确说明已同步到正式数据，且可从最近操作一键回退。
- 未保存草稿切换对象、关闭编辑或离开页面时必须提示用户确认，避免误丢修改。

## 范围

- 管理后台的全站预览中心及其菜单、入口链接。
- Banner、频道、品牌、专题、商品的可视化常用字段编辑。
- 不改变现有商品、内容管理、导入导出、权限和后端保存接口。

## 验收标准

- 用户可从左侧一级菜单在一个动作内进入“可视化装修”。
- 页面首屏显示三步操作引导和“未保存/草稿/已保存”状态。
- 必填字段、图片来源、跳转目标、价格、库存、排序均有可理解的就地提示和约束。
- 空名称、缺失必需图片、无分类商品、负价格/库存、商品市场价低于售价、库存变化未填写原因均不能保存。
- 编辑中的草稿在预览中实时反映；取消可恢复正式数据；保存后的最近一次操作可一键回退。
