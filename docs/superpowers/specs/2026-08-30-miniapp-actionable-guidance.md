# 小程序可执行引导规格

## 目标

当用户无法继续关键流程时，页面不仅说明缺少什么，还必须提供清晰、可直接执行的下一步操作，避免游客或首次用户被留在原页面。

## 规则

- 下单缺少收货地址时，结算页必须稳定展示“添加收货地址”入口。
- 用户首次进入无地址结算页、或点击提交订单时，均须提供“去添加”确认操作；确认后直接进入新增收货地址页。
- 提示文案必须说明阻断原因和下一步，例如“下单前需要添加收货地址”。
- 同类关键交易阻断后续统一采用“原因 + 可执行入口”的模式；纯输入格式错误仍以字段旁提示或简短提示为主。
- 失效商品必须允许用户一键清理；下单失败要按地址、商品状态和优惠券等原因给出正确去处。
- 商品规格未选完整时，必须自动突出当前页的规格选择区；无物流信息要按订单状态解释“未发货”或“物流同步中”。

## 验收标准

- 新游客进入结算页时可看到空地址入口，且会收到一次可跳转的新增地址引导。
- 无地址点击“提交订单”后，不会只出现 toast；用户可点“去添加”直接进入新增地址页。
- 从新增地址页保存返回结算页后，地址会被自动选中并可继续下单。
- 失效商品、下单失败、规格缺失和无物流信息均有明确下一步或可理解的状态说明。
