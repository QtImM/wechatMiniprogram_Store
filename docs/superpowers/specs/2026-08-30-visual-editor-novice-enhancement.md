# 可视化装修小白增强规格

## 目标

在不改变商品、内容、权限和回退既有接口的前提下，让首次使用后台的客户能清楚完成“选择内容、修改、确认发布、发现问题后回退”的闭环。

## 范围

- 可视化装修页提供固定的草稿修改摘要、放弃修改和发布前检查入口。
- 正式保存前展示变更摘要与必填校验、内容质量提醒；确认后才写入正式数据。
- 首页和内容位预览可打开完整内容选择器，避免仅展示前几条造成误解。
- Banner、频道可将已选跳转目标转成人话说明，并可在预览中测试常见目标。
- 默认启用新手模式，隐藏排序权重等非高频字段；用户可展开更多设置。
- 图片提供展示比例建议和比例不匹配提醒；提醒不阻塞保存。
- 保存成功后展示最近一次发布的可撤销提示，继续复用既有快照回退能力。

## 非目标

- 不新增后端接口、服务端草稿、多用户锁定或真实微信预览二维码。
- 不在可视化装修中重建复杂 SKU 规格矩阵。
- 不由 AI 自动生成或自动发布食品文案。

## 验收

1. 任意编辑字段后，页面固定操作条显示未保存状态、变更数量、放弃和检查发布按钮。
2. 发布操作先展示检查结果和变更摘要；存在错误时不能发布，只有提醒时可确认继续发布。
3. Banner、频道、品牌、专题、商品均能在“查看全部内容”中被选中编辑。
4. Banner、频道的跳转目标显示可读名称，商品、专题和固定页面能跳至对应预览位置进行检查。
5. 新手模式默认不显示排序权重，展开更多设置后可正常修改并保存。
6. 管理后台类型检查、构建和 `git diff --check` 通过。
