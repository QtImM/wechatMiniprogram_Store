# 小白友好保存校验规格

## 目标

让运营人员在修改内容名称、价格或常用展示信息时，能够在保存前知道具体问题和修改位置；保留数据安全校验，但不以模糊的组合报错或无关必填项阻断简单修改。

## 规则

- 名称重复、跳转重复、品牌重复、专题重复必须分别提示冲突字段和已占用对象，不得使用“名称或地址不能重复”这类组合错误。
- 可视化装修在前端预先检查当前已加载数据，命中重复时不发送保存请求。
- 品牌图和专题图为可选历史字段；下架商品可不补主图。上架商品仍必须具备主图和有效价格/规格。
- 频道、Banner 可以选择“不跳转”；空跳转不参与重复校验。
- 修改既有内容时，只校验本次实际变更的名称或跳转目标；历史遗留的重复跳转不应阻止一次纯改名操作。
- 后端仍是最终校验来源，防止并发或绕过界面的异常写入。

## 验收标准

- 修改频道名称时，若名称重复，页面明确提示“频道名称已存在”，不再笼统提示名称或地址重复。
- 跳转地址冲突时，页面明确提示已被哪个频道或 Banner 使用。
- 频道已有重复跳转时，仅修改频道名称可以正常保存；操作员主动修改跳转目标为冲突值时才会被拦截。
- 仅修改品牌或专题名称不会因未补图片被拦截。
- 下架商品仅修改名称时，不会因没有主图被拦截；重新上架时仍会强制检查主图、售价与规格。
