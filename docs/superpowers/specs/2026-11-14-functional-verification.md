# 前后端功能交付检查补充规格

覆盖现有约定范围：首页商品、分类搜索、登录会话、地址购物车、优惠结算、支付查单、订单履约、售后退款、评价反馈、后台商品与权限、数据一致性和恢复。继承最终交付规格，不新增经营范围。

页面异常必须结束等待并允许恢复；支付成功以服务端确认结果为准；支付结果页调用的方法必须真实导出。图片评价等待所有上传完成，最多四张，上传失败可重试，提交防重复。前端行为以加载实际源码的自动测试验证，不能仅靠关键词检查。

最终报告按源码提交及环境记录通过、失败和待验证；隔离Mock、静态契约、浏览器和真实渠道证据分别列出。所有关键缺陷关闭、对应回归通过才允许对应交付；无法承诺未知环境永远无缺陷。

地址必须覆盖中国大陆31个省级地区及来源数据中的市区县；不再返回演示区县。采用固定版本MIT授权数据，记录来源、完整性及更新方式；接口不依赖运行时外网。保留旧地址，保存新地址时校验层级并使用规范名称，兼容旧2位省/4位市编码。来源数据仍需随行政区划变化更新，不代表所有地区可配送，实际配送范围由经营规则决定。
