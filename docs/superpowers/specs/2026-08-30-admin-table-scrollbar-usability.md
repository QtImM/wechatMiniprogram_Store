# 管理后台列表横向拖动条可用性规格

## 目标

让非技术操作员在窄屏或字段较多的列表中，稳定、清晰地横向查看内容，不把横向滚动误解为缩放整张表。

## 规则

- 表格外框始终占满其父容器且宽度稳定；横向拖动只能移动表格内部列内容。
- 横向滚动轨道与拖动手柄保持可见，不能依赖悬停后才出现的半透明效果。
- 手柄的可拖拽热区不小于 14px 高；悬停和按住时须提供更强的颜色、边框与阴影反馈。
- 拖动过程沿用组件的原生实时滚动，表格内容与手柄位置同步变化。

## 验收标准

- 鼠标移到列表底部后，能一眼看见完整横向轨道与手柄并稳定拖到目标位置。
- 拖动过程中表格总宽不跳变，右侧列实时随手柄移动显示。
- 默认、悬停、按住三种状态均有明显区别且手柄不透明。
