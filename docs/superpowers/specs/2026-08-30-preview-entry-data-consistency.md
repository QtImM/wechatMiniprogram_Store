# 可视化装修入口数据一致性规格

## 目标

从商品列表、商品编辑页、内容管理页或左侧菜单进入可视化装修时，正式数据必须一致；只有用户当前正在编辑且尚未保存时，才允许以草稿覆盖预览。

## 规则

- 加载现有内容到右侧编辑面板不视为修改，不能自动写入草稿。
- 商品列表进入可视化装修时，必须清理旧草稿并重新读取后端正式数据。
- 草稿保留用于跨页面实时预览，但超过 15 分钟未更新时自动失效，避免历史草稿长期覆盖正式数据。
- 草稿状态必须清晰标记，不得伪装成正式数据。

## 验收标准

- 商品列表入口和左侧菜单入口看到的未编辑数据一致。
- 仅打开并查看某项内容，不会产生草稿标记。
- 用户修改字段时才出现草稿，并实时反映在预览中。
- 旧草稿不会影响新的预览会话。
