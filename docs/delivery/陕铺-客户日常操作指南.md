# 陕铺客户日常操作指南

适用：本次交付候选版。后台地址、运营账号与初始密码由交付人员安全提供。微信公众平台账号名称和备案由账号负责人管理，此处的“店铺展示设置”仅修改页面展示。

## 第一次登录

使用交付网址登录，立即修改初始密码。商品运营使用独立账号，不共用超级管理员。录入阶段登录后进入商品列表；订单和财务功能在商城开放后按岗位权限显示。

## 先准备分类和图片

1. 打开“商品管理 → 分类管理”，确认分类名称和层级。
2. 打开“商品管理 → 素材库”，上传商品主图、轮播图和详情图。
3. 上传失败时查看格式和大小提示，重新选择图片。不要使用微信临时图片路径或本机文件地址。
4. 已被商品、内容或店铺 Logo 使用的素材不能直接删除，先更换引用后再处理。

## 新增商品

1. 打开“商品管理 → 商品列表 → 新增商品”。
2. 填名称、分类、商品说明，选择主图、轮播图和详情图片。
3. 单规格商品填写价格、库存；多规格商品先建立规格和规格值，再逐行核对每个 SKU 的价格和库存。
4. 页面显示人民币“元”，不要手工乘以 100；库存填写整数。
5. 新商品默认“下架”。保存后检查列表和预览，确认名称、图片、价格与规格正确。
6. 商城开放且资料核实后再明确选择“上架”。保存草稿不等于公众已经能购买。

## 修改商品与库存

在商品列表打开编辑，检查改动后保存。调整库存时填写真实原因，库存工作台可查流水。已有订单中的价格与商品信息是下单快照，修改商品不改变旧订单。

可视化装修可以修改常用展示内容。商品历史恢复只恢复展示信息，不恢复库存、价格或规格集合；这些内容请使用专门的价格、库存及商品编辑功能，避免把卖出的库存加回。

## 批量导入商品

1. 在商品列表下载当前后台的 Excel 模板，模板字典以实际分类为准。
2. 按“填写说明”填写，先用一件商品试导入；多规格商品使用相同商品组编码。
3. 选择新增、更新或补充规格模式，先执行预校验。
4. 修正失败行后再确认导入。预校验不会写入正式商品。
5. 更新已有商品时按模板规则提供完整 SKU 集合；不要仅保留想修改的一行。
6. 导入后检查成功数量、规格、价格、库存及图片。

## 店铺名称和 Logo

授权管理员在“系统管理 → 店铺展示设置”修改展示名、Logo、简介及客服联系方式。Logo 从素材库选择。保存后重新打开小程序核对；这一步不会替你修改微信公众平台的名称或备案记录。

## 商城开放后的订单与售后

客服在订单列表筛选待发货，核对订单、物流公司和真实单号后发货。用户可以查看物流并确认收货，在订单详情选择商品评价。若微信平台要求额外的发货信息录入，按交付时明确的自动同步或人工流程逐单核对。

售后人员按退货退款政策审核。退款显示“处理中”时先查询或同步状态，不能因为没有立即到账就重复操作；失败或不确定的退款交由售后及财务岗位核对渠道记录。

财务每日检查支付异常、退款异常及前一日对账。只有本地订单和真实渠道记录核对一致，才算资金处理完成。

## 遇到问题

记录发生时间、页面、商品或订单号、提示截图和操作步骤，通过约定的支持渠道反馈。不要发送密码、支付密钥、完整收货资料或证书。不能确认是否支付/退款成功时，先保留现场并核对订单与渠道，避免重复付款或退款。

交接验收时请独立完成：新增一件真实商品、上传图片、修改一个规格、试导入一行、处理一次测试发货及售后，并确认知道如何查看库存与对账。真实后台截图和培训记录应由交付人员在部署验证后补入验收报告，本文不使用未经验证的示意截图代替实际界面。
