# 教程维护说明

## 给阅读者

- 双击 `操作教程.html` 阅读。点击左侧目录可直接跳到对应任务，点击截图可打开原图。
- 用浏览器的查找功能（Ctrl+F）搜索“改价”“库存”等词。
- 发给别人时，压缩整个 `shanpu-admin-guide` 文件夹；HTML 和 `images` 文件夹必须一起保留。
- 如果只需要打印，可在 HTML 左侧点击“打印 / 保存为 PDF”。

## 给编辑者

1. 用 VS Code、Typora 或普通文本编辑器修改 `操作教程.md`，保持 UTF-8 编码。
2. 截图放在 `images` 中。替换同名图片时，不需要修改正文引用。
3. 在本目录运行 `python 生成阅读版.py`，生成更新后的 `操作教程.html`。
4. 生成脚本需要 Python 3.10+，依赖使用 `python -m pip install -r requirements.txt` 安装；只有编辑时需要，阅读 HTML 不需要安装任何程序或联网。
5. 正文是唯一内容源，不建议单独编辑生成的 HTML 正文，否则下一次生成会覆盖该处修改。
6. 检查目录、表格、所有截图与原图链接，再重新压缩整个文件夹。
