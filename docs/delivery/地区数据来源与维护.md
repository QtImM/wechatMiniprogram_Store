# 地区数据来源与维护

固定来源：`@vant/area-data` 2.2.0，项目 https://github.com/vant-ui/vant/tree/main/packages/vant-area-data 。下载地址及SHA512完整性保存在 `scripts/generate_region_catalog.py`；MIT版权及许可证随资源保留。

离线资源包含31个大陆省级、342个市级、3061个区县级记录。数据用于选择和校验收货地址，不等于承诺配送到所有地区，也不是对当前行政区划零差异的保证。正式交付须核对实际经营区域及承运商支持。

维护人员运行生成脚本，仅在包完整性符合固定值、层级和数量检查通过后更新资源，不执行下载包内代码。更换版本时核对上游数据变动、许可证及新完整性值，重跑地区和地址测试。上游说明地区数据可能随行政区划变化，需要持续维护。

接口返回6位编码，保存兼容旧2位省/4位市编码；保存时校验省市区所属关系并使用数据源规范名称。不会批量覆盖旧地址；旧演示区县不在真实数据中的，编辑保存时提示重新选择。未知地区返回空列表，不自动编造“城区/新区”。
