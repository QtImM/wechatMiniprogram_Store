# v1.0 客户资料一次性收集表

> 用途：交付前一次性向客户收齐真实上线资料。未收齐前，可以继续完成代码交付和本地验收，但不能完成微信体验版、真实支付退款、真实物流和生产签收。

## 1. 填写说明

| 项目 | 说明 |
|------|------|
| 填写人 | 客户项目负责人或指定对接人 |
| 资料接收人 | 项目交付负责人 |
| 密钥类资料 | 不通过微信、邮件明文发送，使用客户认可的安全方式交付 |
| 证书类资料 | 只放服务器安全目录，不进入 Git 仓库 |
| 截止时间 | 待客户确认 |

## 2. 微信小程序资料

| 资料项 | 用途 | 格式或要求 | 客户填写 |
|--------|------|------------|----------|
| 小程序 AppID | 小程序登录、支付 AppID | 以 `wx` 开头 | 待提供 |
| 小程序 AppSecret | 服务端微信登录 code2session | 密钥，安全交付 | 待提供 |
| 小程序名称 | 提审与客户验收 | 与客户主体一致 | 待提供 |
| 小程序服务类目 | 微信提审 | 与实际经营商品匹配 | 待提供 |
| 小程序头像 | 微信后台配置 | PNG/JPG | 待提供 |
| 小程序简介 | 微信后台配置 | 客户确认文案 | 待提供 |
| 微信开发者权限 | 上传体验版和提审 | 交付人员或客户自行上传 | 待确认 |

## 3. 域名和证书资料

| 资料项 | 用途 | 格式或要求 | 客户填写 |
|--------|------|------------|----------|
| 已备案正式域名 | 后端、后台、小程序合法域名 | HTTPS 域名 | 待提供 |
| HTTPS 证书 | Nginx 生产 HTTPS | `fullchain.pem`、`privkey.pem` 或客户证书方案 | 待提供 |
| 后端 API 域名 | 小程序 request 合法域名 | 例如 `https://shop.example.com` | 待提供 |
| 管理后台域名 | 客户后台访问 | 可与 API 同域或独立域名 | 待提供 |
| 上传域名 | 微信 uploadFile 合法域名 | HTTPS | 待提供 |
| 下载域名 | 微信 downloadFile 合法域名 | HTTPS | 待提供 |
| 静态素材访问域名 | 商品图片公开访问 | HTTPS，映射 `/uploads/material/` | 待提供 |

## 4. 微信支付和退款资料

| 资料项 | 用途 | 格式或要求 | 客户填写 |
|--------|------|------------|----------|
| 微信支付商户号 | JSAPI 支付和退款 | 数字商户号 | 待提供 |
| 商户 API 证书序列号 | 微信支付签名 | 商户平台可查看 | 待提供 |
| 商户 API 私钥 | 服务端请求签名 | `apiclient_key.pem`，安全交付 | 待提供 |
| 微信支付平台证书 | 回调验签 | `platform_cert.pem` 或下载方式 | 待提供 |
| API v3 Key | 回调解密和退款 | 32 字节，安全交付 | 待提供 |
| 支付回调域名 | 微信支付通知 | `https://<域名>/app-api/pay/wechat/notify` | 待确认 |
| 退款回调域名 | 微信退款通知 | `https://<域名>/app-api/pay/wechat/refund-notify` | 待确认 |
| 商户平台协作人 | 实单验收支持 | 可查看交易、退款和账单 | 待提供 |
